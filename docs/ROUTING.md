# Подключение к Discord, играм и OBS

VoxLab — приложение обработки звука. Системный микрофон для других программ создаёт **установленный виртуальный аудиокабель**.

## Схема

```text
Физический микрофон → VoxLab → CABLE Input (выход воспроизведения)
                                      ↓
                              CABLE Output (вход записи) → Discord / игра / OBS
                        ↘ отдельные наушники: прослушивание из VoxLab
```

Названия Input/Output у VB-CABLE описывают стороны кабеля, поэтому на первый взгляд кажутся перепутанными.

## Если виртуального кабеля нет

В комплекте находится **неизменённый оригинальный архив VB-Audio Virtual Cable (VB-CABLE Basic)**: `Drivers/VB-CABLE/VBCABLE_Driver_Pack45.zip`. В разделе «Устройства» нажмите **Открыть архив VB-CABLE** — откроется папка с выделенным архивом.

1. Распакуйте архив кабеля в отдельную папку.
2. Самостоятельно запустите `VBCABLE_Setup_x64.exe` от имени администратора, ознакомьтесь с лицензией и установите драйвер.
3. Перезагрузите Windows, затем снова откройте VoxLab.

VoxLab не запускает и не автоматизирует установку: условия издателя разрешают распространять исходный пакет без изменений, но запрещают включать его установку в процедуру установки другого ПО без отдельного соглашения. Источник — [www.vb-cable.com](https://www.vb-cable.com). **Donationware:** добровольная поддержка автора приветствуется. Полные условия находятся в `readme.txt` внутри оригинального архива.

Сам VoxLab переносится одной папкой. **Драйвер переносимым не является:** на другом ПК его нужно установить отдельно; удаление папки VoxLab не удаляет драйвер. Для удаления кабеля используйте его оригинальный установщик.

После установки нажмите **Обновить список** в VoxLab. Подойдут и другие уже установленные виртуальные устройства, если у них есть парные playback/capture-стороны.

## Настройка

1. В VoxLab → **Устройства → Вход** выберите физический микрофон.
2. В **Выход в приложения** выберите **CABLE Input**.
3. В Discord → настройки голоса, либо в игре/OBS → источник микрофона, выберите **CABLE Output**.
4. В VoxLab выберите голос и нажмите **Запустить голос**.
5. Чтобы слышать себя, остановите движок, включите **Слышать себя**, выберите физические наушники и запустите снова. Не выбирайте для мониторинга сам виртуальный кабель.

Не включайте одновременно прослушивание этого же микрофона в Windows, Discord и VoxLab: появятся дублирование и дополнительное эхо. Начните с небольшой громкости наушников.

## Проверка без кабеля

Выберите в качестве выхода физические **наушники**. Вы сможете слышать результат и сохранять WAV, однако другие приложения сами по себе этот звук как микрофон не получат. По умолчанию физические динамики не выбираются, чтобы не создавать обратную связь.

## Настройка качества

- Начните с 40 мс. При треске/прерываниях попробуйте 80 мс; если система стабильна — 20 мс.
- По возможности поставьте 48 кГц у микрофона и виртуального кабеля в Windows. Движок поддерживает текущую частоту микрофона и преобразует формат для устройства вывода.
- Сильное шумоподавление принимающего приложения может удалять роботизацию и хвосты эффектов. Уменьшайте его только при необходимости.
- Если начало слов исчезает, понизьте порог гейта; если тихий фон остаётся между словами, немного повысьте.
- Перед изменением устройств остановите обработку. Запись при этом будет завершена.

Если устройство отключилось во время работы, VoxLab останавливает поток и показывает ошибку. Подключите устройство, обновите список, выберите его и запустите снова.
