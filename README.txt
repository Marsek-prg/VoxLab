VoxLab 0.2.1 — Portable для Windows 10/11 x64

1. Распакуйте ВСЮ папку в доступное для записи место.
2. Откройте VoxLab.exe. Устанавливать VoxLab или .NET не нужно.
3. В «Устройствах» выберите микрофон и выход, затем пресет.
4. Нажмите «Запустить голос». Для прослушивания используйте наушники.

В корне находятся только VoxLab.exe, эта инструкция и папки App / Data.
Все служебные файлы лежат в App — открывать её для запуска не нужно.
Не переносите EXE отдельно: переносите всю папку приложения.

ДЛЯ DISCORD / ИГР / OBS
Оригинальный виртуальный кабель уже приложен:
App/Drivers/VB-CABLE/VBCABLE_Driver_Pack45.zip
В приложении есть кнопка открытия его расположения и инструкция.
Самостоятельно распакуйте архив и запустите VBCABLE_Setup_x64.exe
от администратора, ознакомьтесь с условиями издателя и перезагрузитесь.
VoxLab: выход CABLE Input. Discord / игра: микрофон CABLE Output.
Кабель — системный драйвер, поэтому на каждом ПК устанавливается один раз.
VoxLab остаётся переносимой программой и не устанавливает драйвер сам.
Без кабеля доступны эффекты в наушниках и запись WAV.

ДАННЫЕ И ОБНОВЛЕНИЕ
Настройки и кеш: Data рядом с VoxLab.exe.
Обновление: Настройки → Проверить обновления → Скачать → Перезапустить.
Переносите всю папку. Data с настройками и записями сохраняется.
Первый переход с 0.1.1: закройте программу и распакуйте этот ZIP
поверх прежней папки с заменой файлов; Data в архиве отсутствует.
С версии 0.1.0: распакуйте этот релиз в новую папку и скопируйте туда Data.
Микрофон не запускается автоматически. Крестик сворачивает окно в системный трей.
Повторный запуск EXE возвращает окно. Полный выход — через меню значка в трее.
Ползунки сохраняются отдельно для каждого голоса; стрелка сбрасывает выбранный голос.
На ПК нужен Microsoft Edge WebView2 Runtime (обычно уже установлен).

Горячие клавиши: Ctrl+Alt+S — старт/стоп; Ctrl+Alt+M — mute;
Ctrl+Alt+B — обход эффектов; Ctrl+Alt+1…8 — первые восемь пресетов.
Свои сочетания назначаются в разделе «Настройки».
24 пресета; сила эффекта 0–200%; новые биткрашер, тремоло и флэнжер.

Пресеты используют DSP, а не клонирование голосов. Возможна пауза при
включении pitch. Начните с буфера 40 мс; при треске попробуйте 80 мс.
